# FinTrack – Personal Finance & Investment Portfolio Platform

A beginner-friendly Angular project made as a student main project. It provides a simple dashboard to manage sample income, expenses, budget, investments and savings goals.

## Modules
1. Income, Expense & Budget Management
2. Investment Portfolio & Asset Allocation
3. Financial Goals, Savings Plans & Calculators (goal progress is included; calculators can be added)
4. Analytics Dashboard, Trends & Exportable Reports (dashboard summaries and expense CSV export included)

## Run locally
1. Install Node.js (LTS) and Angular prerequisites.
2. Open this folder in VS Code.
3. In terminal run:
   ```bash
   npm install
   npm start
   ```
4. Open the local URL shown by Angular (usually http://localhost:4200).

## Notes
- Data is sample data stored in component memory. Refreshing the browser resets changes.
- Investment values are illustrative and not live market data or financial advice.
- This is a front-end demo; no login or backend/database is connected yet.
